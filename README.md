# Harvard CV Generator

A complete standalone, single-file HTML application for generating Harvard-style CVs in the browser. 
It is completely free, runs entirely offline (using CDNs), and requires no account.

## How to Use

1. **Fill the Form:** Enter your personal information, experience, education, and skills. The app supports English and Spanish seamlessly.
2. **Preview PDF:** See your updates live in the preview pane. 
3. **Save/Load JSON:** Save your data locally as a `.json` file by clicking "Save JSON". You can load it back later by clicking "Load JSON".
4. **Download PDF:** Generate and download your Harvard-style CV by clicking the export buttons in the sidebar.
